# Archipelago Technical Requirements Document (TRD)

## 1. System Overview
Archipelago is a curriculum-aware Hybrid Graph-Vector RAG Institutional Library Intelligence System. 

The core architecture operates via a **3-service Flask/Gunicorn cluster**:
- `inference:5151` - Core business logic, routing, intent classification, and synthesis.
- `graph:5150` - KùzuDB-powered graph database endpoint for structural retrieval.
- `chat:5152` - Frontend-facing gateway handling SSE streams and UI routing.

A **local ingestion appliance** operates alongside the hosted infrastructure to process heavy binary assets (PDFs, spreadsheets, images) before shipping OKF (Open Knowledge Format) artifacts to the graph.

## 2. Query Pipeline Technical Spec

The lifecycle of a user query moves through a strict 12-stage pipeline:

```
USER QUERY → Firewall (<2ms) → Query Cache (LRU 512) → 12-Branch Router → Scope Gate → Intent Classification → Domain Detection → Graph Retrieval (KùzuDB K-hop) → Hybrid Ranking (Arctic embed + Lexical) → Private-Data Filter → Context Assembly → LLM Gateway (xkiro→NVIDIA→Gemini→Ollama) → Citation Wrapper → SSE Stream → Chat UI
```

### Component Details
- **Firewall & Scope Gate**: Implemented in `archipelago/core/router.py`. Executes under 2ms. Checks for prompt injection patterns and limits length to 500 characters.
- **Router (Inference Engine)**: Handled by the `Engine` class in `host_inference/engine/answer.py` and strictly bound to contracts defined in `host_inference/engine/contract.py`.
- **Graph Retrieval**: Handled by `LibraryGraph` in `host_inference/engine/graph.py`. Executes K-hop BFS resolving `prereqs` and `unlocks`.
- **Hybrid Ranking**: Located at `archipelago/inference/ranking.py`. Fuses Snowflake Arctic embeddings with lexical (BM25/Fuzz) scoring.
- **LLM Gateway**: Managed in `host_inference/engine/llm.py` via `stream_completion`. Fallback chain: `xkiro` → `NVIDIA NIM` → `Gemini` → `Ollama`.
- **Context Assembly**: Synthesis logic in `host_inference/engine/compose.py` generating comparative matrices and relation chains.
- **Citation Wrapper**: Generated by `host_inference/engine/links.py` mapping retrieved nodes to `inventory_card.py` definitions.

## 3. Intent Routing Spec
The system utilizes 6 strict response contracts, mapping 19 internal classification routes.

- **Contracts** (`host_inference/engine/contract.py`):
  1. `GRAPH_SYNTHESIS`
  2. `CATALOG_SHELF_ROUTING`
  3. `AUTH_GATEWAY`
  4. `MCQ_DIAGNOSTIC`
  5. `INGESTION_ANALYSIS`
  6. `GUARDRAIL_INTERCEPT`
- **Detection Patterns** (`patterns.py`): Uses RegEx-based heuristics (`SCHEDULE_RE`, `SHELF_RE`, `AUTH_RE`, `DIAG_RE`, `INGEST_RE`, `RELATE_RE`, `PARAM_RE`).
- **Confidence Gating** (`archipelago/core/router.py`):
  - `>= 0.75`: Execute route directly.
  - `0.50 - 0.75`: Suggest execution (clarify with user).
  - `< 0.50`: Reject/Fallback to general query.
- **Graph Render Decision**: Pure function evaluating if `contract_type in {GRAPH_SYNTHESIS, MCQ_DIAGNOSTIC, INGESTION_ANALYSIS}`.

## 4. Graph Infrastructure Spec
Graph state is maintained via KùzuDB and mapped to memory for inference speed.

- **KùzuDB Schema**:
  - **Nodes**: `Concept` (id, label, name, summary, concept_type, difficulty, sources), `Document`, `Chunk`, `Resource` (call_number, barcode, copies), `Subject`.
  - **Edges**: `REQUIRES`, `UNLOCKS`, `RELATED`.
- **Data Layers**:
  - *Memory*: `okf_graph.json` loaded into memory via `LibraryGraph` for high-throughput API endpoints.
  - *Disk*: Full KùzuDB state (`okf_graph.db`, ~100MB) utilized on local ingestion instances.
- **Traversal**: Algorithms implemented include BFS K-hop (`_walk()`), `prereqs()`, `unlocks()`, and `shortest_dependency_path()`.
- **Hot-swapping**: Updates execute via atomic POSIX rename to guarantee zero-downtime graph reloads.

## 5. Ingestion Pipeline Spec
Heavy ingestion runs offline or asynchronously via workers.

- **PDF Parsing**: PyMuPDF (`fitz`) coupled with `pdf_chunk.py` to extract section-aware text chunks.
- **OCR Processing**: Tesseract (via `pytesseract`) + `Pillow` located at `archipelago/ingestion/page_image/`.
- **Spreadsheets (ODS/CSV)**: Safely parsed using `defusedxml` + `odfpy` in `archipelago/ingestion/spreadsheet/`.
- **OKF Extraction Engine**: Uses `lib-qwen` small model, located in `archipelago/ingestion/lib_qwen_extractor/`.
- **Graph Fusion Validation**: `okf/pipeline.py` hands off to `graph_fusion.py` to enforce Kahn DAG cycle-check validation before database commits.
- **Task Worker**: Managed by `archipelago/ingestion/librarian_worker/`.

## 6. Personalized Learning Spec
- **Diagnostic Engine** (`host_inference/engine/diagnostics.py`):
  - Requires update: `MCQ_MAX_QUESTIONS` and `CHECKPOINT_QUESTIONS` must be changed from `4` to `10`.
- **Pathfinder** (`host_inference/engine/pathfinder.py`): Utilizes A* search to generate optimal learning paths across graph prereqs.
- **MCQ Generation**: Distractor pool uses 8 adjacent neighbors from the graph.
- **Mastery State Machine**:
  - *Current*: 🟢 Mastered, 🟡 Review Gap, 🎯 Target.
  - *Required/Missing*: 🟠 Fading, 🔴 Missing states, time decay factors, and confidence calibration inputs.

## 7. Caching Architecture
Located in `host_inference/cache_service.py` to minimize redundant LLM and Graph operations.
- **3-Tier Supabase Cache**: `ai_response_cache`, `retrieval_cache`, `graph_cache`.
- **Versioned Keys**: Fingerprints are generated via `hash(query + graph_version + library_version + model_version + prompt_version)`.
- **TTL Profiles**: Response (1h), Retrieval (30m), Graph (2h).
- **Concurrency Control**: Request deduplication via Python threading locks.
- **Resilience**: Silent local fallback when Supabase is unreachable.

## 8. Embedding/Retrieval Spec
- **Vector Model**: Snowflake Arctic embed. Utilizes DIM=384 local hashing for fast lookup, optional full 1024-dim scaling for deeper semantic tasks.
- **Kill Switch**: Cosine similarity `< 0.75` will immediately abort retrieval.
- **Lexical Fallback**: TheFuzz (Levenshtein distance).
- **Alias Management**: `constants.py` exports `ALIASES` dict utilized by `alias_index.py`.

## 9. Deployment Spec
- **Platform**: AntDeploy configuration defined in `.antideploy.json` (app ID, env vars, commands).
- **Containers**: Base `python:3.12-slim`, installed with `tesseract-ocr` and `gunicorn`. Orchestrated via `docker-compose.yml`.
- **Service Mesh**:
  - Port `5150`: Graph service.
  - Port `5151`: Inference service.
  - Port `5152`: Chat proxy.
- **Entrypoint**: Production requests route through `host_inference/hostapp/wsgi.py`.
