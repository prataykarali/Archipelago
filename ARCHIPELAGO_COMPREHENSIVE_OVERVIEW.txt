1. EXECUTIVE SUMMARY & WHAT THE APP DOES
--------------------------------------------------------------------------------
Archipelago is an open-source, local-first, domain-agnostic Knowledge Graph
pipeline and pedagogical AI Librarian platform. Originally seeded with an
exhaustive Artificial Intelligence & Machine Learning (AI/ML) corpus, Archipelago
transforms raw unstructured documents (PDFs, Markdown, scientific papers, and
textbooks) into a structured Open Knowledge Format (OKF v1.6) graph database.

Unlike conventional conversational LLM wrappers or generative "homework solvers",
Archipelago strictly implements "The Doorstep Model" (Pedagogical Cartographer):
- It never solves student homework or generates production code outright.
- Instead, it acts as an expert academic research librarian at the doorstep of the
  knowledge archives, guiding learners to first principles, upstream prerequisites,
  foundational mathematical concepts, downstream unlocks, and primary literature
  citations (with exact page and section numbers).
- It provides interactive visual maps of knowledge topology, diagnostic
  multiple-choice verification checks (Socratic assessment), and multi-hop
  curriculum roadmaps.

4. COMPLETE CATALOG OF ALL FEATURES
================================================================================

FEATURE 1: "The Doorstep Model" Pedagogical Cartographer
- Prevents cognitive outsourcing: will not write code snippets, complete coding
  exercises, or solve assignment questions.
- Re-anchors learner queries into foundational prerequisites, architectural
  taxonomy, theoretical mechanisms, and original research literature.
- Prompts students to reflect, inspect dependencies, and verify their knowledge.

FEATURE 2: The 8-Key Open Knowledge Format (OKF v1.6) Schema
Every concept ingested or generated conforms to 8 canonical keys:
  1. concept_name: Title Case noun phrase (<= 5 words).
  2. concept_type: method | metric | technique | theory | tool | dataset | result | definition.
  3. difficulty: foundational | intermediate | advanced | expert.
  4. summary: 1-2 sentence definition focusing on functional mechanisms.
  5. prerequisites: List of required concepts that strictly precede this node.
  6. unlocks: List of downstream advanced concepts enabled by mastering this node.
  7. related_to: Array of typed directional edges:
     - uses | extends | contrasts_with | evaluated_by | variant_of | part_of
  8. tags: Lowercase-hyphenated taxonomical categorizations.

FEATURE 3: 12 Operational OKF Reply Mechanisms
Archipelago classifies user intent across 12 distinct pedagogical response modes:
  1. Architectural & Functional Taxonomy (concept_type focus):
     Explains where an entity sits in the ML stack without reciting entire chains.
  2. Curriculum Difficulty & Cognitive Scaffolding (difficulty & prerequisites):
     Structures a progressive, step-by-step ladder for beginners or advanced users.
  3. Upstream Dependency & Prerequisite Audit (prerequisites focus):
     Maps out all essential foundational topics required before tackling a concept.
  4. Downstream Application & Unlock Forecast (unlocks focus):
     Visualizes future capabilities and advanced algorithms enabled by this topic.
  5. Comparative & Dialectical Analysis (contrasts_with edge focus):
     Directly contrasts competing methods (e.g., LoRA vs Full Fine-Tuning;
     Dense RAG vs GraphRAG).
  6. Evolution & Lineage Tracing (improves_on / variant_of edge focus):
     Traces historical advancements from predecessor algorithms to current state.
  7. Compositional & Stack Deconstruction (uses / part_of edge focus):
     Breaks down a complex system into its internal building blocks (e.g., Transformer
     broken down into Multi-Head Attention, Softmax, LayerNorm, Positional Encoding).
  8. Cross-Domain Transfer & Thematic Clustering (tags focus):
     Connects related techniques across disparate fields (e.g., NLP to Computer Vision).
  9. Socratic Assessment & Diagnostic MCQs:
     Generates 3-question diagnostic quizzes with real-time verification to validate
     student mastery before advancing down the curriculum.
  10. Multi-Hop Curriculum Roadmap Planning (/api/roadmap/plan, /api/roadmap/between):
      Computes shortest and most pedagogically sound graph paths between concepts A and B.
  11. Out-of-Corpus Fallback & Institutional Redirection:
      Gracefully catches out-of-scope non-AIML queries (e.g. astrology, baking) and guides
      students back to indexed computing resources with zero LLM token waste.
  12. Librarian Staging & Review Ingestion (/api/librarian/upload):
      Allows librarians to upload PDFs, run automated extraction, inspect parsed nodes
      in staging, edit definitions, and publish atomically to the live graph.

FEATURE 4: Deterministic Gateway Interceptor & Safety Firewall
- Operates at < 2 ms before reaching any LLM inference:
  * Strict 500-Character Query Limit: Prevents buffer overruns and context attacks.
  * Prompt Injection Firewall: Heuristic and regex filter detecting jailbreaks,
    system prompt overrides, roleplay escapes, and toxic instructions.
  * Institutional Authentication Cards: Emits [RENDER_AUTH_CARD] signals for gated
    or privileged librarian workflows.
  * Out-of-scope Zero-Cost Bypass: Short-circuits non-technical queries without
    incurring cloud LLM API costs.

FEATURE 5: Multi-Model LLM Gateway with Resilient Failover
- Supports dynamic multi-provider routing:
  * Primary Remote Model: xkiro (qwen/qwen3.8-max:free) via OpenAI-compatible gateway.
  * Multi-Tier Cloud Backup: Google Gemini API
    - gemini-2.0-flash: High-speed streaming synthesis with citation grounding.
    - gemini-2.0-flash-lite: Ultra-low latency for query intent classification.
    - gemini-2.5-flash: Complex multi-hop curriculum path synthesis.
    - gemini-2.5-pro: Deep tool-calling and graph reconciliation.
  * Local Air-Gapped SLM: lib-qwen-v44-q8_0.gguf (Fine-tuned QLoRA 0.5B/1.5B parameters)
    for offline extraction directly on university hardware.

FEATURE 6: Interactive Dual-Graph Visualization (60 FPS)
- In-Chat Subgraph View:
  * Dynamically queries the local 2-hop neighborhood of queried concepts.
  * Renders smooth SVG canvas inside the chat stream.
  * Features centered anchor pulsing rings, distinct color coding for node types,
    smooth hover cards, and clickable nodes that instantly redirect the chat.
- Standalone Graph Explorer (Port 5150):
  * Interactive D3.js physics-driven force simulation displaying all 531 concepts
    and 1,890 relationships.
  * Real-time search filter, difficulty thresholds, cluster physics, and an
    inspect drawer showcasing summaries, prerequisites, unlocks, and paper links.

FEATURE 7: Four Specialized Web Portals (Port 5152)
- /chat: The primary student interaction terminal with streaming tokens, inline
  SVG graph preview, literature reading lists, and diagnostic MCQs.
- /library: A visual catalog of 531 concepts with category filters, difficulty
  badges, search bars, and document upload dropzones.
- /performance: Live engineering dashboard displaying latency percentiles (P50,
  P90, P99), TTFT metrics, token throughput, and cache hit ratios.
- /safety: Institutional compliance interface presenting firewall logs, detected
  jailbreak attempts, token spend charts, and active intercept rules.

FEATURE 8: Academic Provenance & Literature Citation Engine
- Grounded Extraction:
  * Every concept in the graph retains source passage provenance (doc_id, chunk_id,
    page number, section title, and verbatim excerpt).
- Citation Delivery:
  * Responses provide direct clickable links to the local PDF repository
    (/pdfs/Filename.pdf#page=N) as well as official arXiv/DOI identifiers.

FEATURE 9: Automated Extraction Pipeline & Graph Fusion
- PDF Section-Aware Chunking: Preserves mathematical formulas and section hierarchy.
- Deduplication & Entity Canonicalization: Fuzzy string matching, acronym expansion
  (e.g., LoRA -> Low-Rank Adaptation), and alias tables.
- Cycle Detection & DAG Enforcement: Eliminates circular prerequisites before merging.
- Atomic Database Swaps: Safely replaces graph databases without interrupting active
  read-only query connections.

FEATURE 10: Production Readiness & Container Packaging
- Containerized deployment via Dockerfile and docker-compose.yml.
- Supervised by Linux systemd user units for auto-restart on failure:
  * archipealgo-inference.service (Port 5151)
  * archipealgo-graph.service (Port 5150)
  * archipealgo-chat.service (Port 5152)
